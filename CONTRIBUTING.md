# Contributing to Soroban ZK Docs

Thank you for helping improve the Soroban ZK Toolkit documentation!

This guide explains how to set up the documentation site locally, create new content, follow writing guidelines, and submit changes.

## Prerequisites

Before getting started, make sure you have:

- Node.js ≥ 18
- pnpm (recommended) or npm
- Git installed

## Local Setup

Clone the repository:

```bash
git clone https://github.com/soroban-zk-toolkit/soroban-zk-docs.git
cd soroban-zk-docs
